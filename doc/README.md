# Documentation

This directory contains documentation, codebooks, and reference materials for the project.

## Survey Documentation

### [`Infas_Auxco_method_report.pdf`](Infas_Auxco_method_report.pdf)

Method report from the 2019 survey administrated by infas. It explains how the data on which the models are fitted was generated.

## Data Documentation

### [`Codebook.xlsx`](Codebook.xlsx)

Codebook for the data. Contains variable description and data structure information for the main dataset.

### [`KldB_classifications.xlsx`](KldB_classifications.xlsx)

Reference document for KldB (Klassifikation der Berufe) classification codes and their meanings.

### [`ISCO-classifications.pdf`](ISCO-classifications.pdf)

Reference document for ISCO (International Standard Classification of Occupations) classification codes and their meanings.

## Methodological References

### [`Dawid_and_Skene_NoisyLabels.pdf`](Dawid_and_Skene_NoisyLabels.pdf)

Original paper by Dawid and Skene (1979) on the model for analyzing noisy labels. This is the foundational methodological reference for the Bayesian approach used in this project.

### [`Stan_Documentation.pdf`](Stan_Documentation.pdf)

Documentation for Stan, the probabilistic programming language used for Bayesian inference in this project.

## Project Documentation

### [`Thesis.pdf`](Thesis.pdf)

Main thesis document presenting the complete research project, methodology, results, and conclusions.

### [`Expose.pdf`](Expose.pdf)

Project expose providing background information and open research questions within the project.
